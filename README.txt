FlyDreamAir LocalStorage Prototype

This is a simplified frontend-only version of the project.
It does not use FastAPI, PostgreSQL, Node.js, or any server.

How to run:
1. Open pages/index.html in a browser.
2. Register a new account or use demo login:
   Email: demo@flydreamair.com
   Password: password123

Data storage:
- Users, bookings, selected seats, and add-ons are saved in browser localStorage.
- To reset the demo data, clear browser site data/localStorage.
