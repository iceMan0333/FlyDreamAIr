# FlyDreamAir

FlyDreamAir is a static airline booking website prototype with pages for flight search, destination browsing, account access, booking management, seat services, payment, confirmation, receipts, and help.

## Project Structure

- `index.html` - homepage and booking form entry point
- `homepage/` - homepage layout, booking, trending destination styles, scripts, and images
- `destinations/` - destination gallery page
- `selectFlight/` - flight selection page
- `seat&services/` - seat and onboard service pages
- `cardDetails/` - payment card form
- `confirmation/` - booking confirmation page
- `receipt/` - receipt page
- `manageBooking/` and `bookingchanges/` - booking lookup and change flows
- `login/`, `signup/`, and `profile/` - account pages
- `help/` - support page
- `theme.css`, `flydreamair-ui.css`, and `flydreamair-ui.js` - shared styling and UI behavior

## Running Locally

Open `index.html` in a browser to view the site. Because this is a static prototype, no build step or server is required for the main pages.
